## 🚀 Featured Projects

### USSD Canvas

**A visual flow builder for USSD services** — design, test and ship USSD menu journeys on a drag-and-drop canvas instead of hard-coding them.

- Build flows visually — menu, input and end screens wired together on a canvas
- Conditional routing: send users down different paths based on what they enter or what an external service returns
- Call external APIs mid-journey and reuse the response further down the flow
- Simulate a complete journey in the browser before it goes live
- Single sign-on with centrally managed access

Java · Spring Boot · PostgreSQL · Next.js · React · TypeScript
